Your agents, your logins.

Agentloft drives each agent through its own structured protocol, never by scraping a terminal: exact streaming, tool calls, approvals, interrupts and resume. Agents sign in with their own CLI, so Agentloft never sees an API key.

  • Claude Codestream-json control
  • Codexcodex app-server
  • Gemini CLIAgent Client Protocol
  • OpenCodeAgent Client Protocol
  • Any ACP agentsame protocol
  • Model and permission mode per thread
  • Queue messages while a turn runs
  • Agents can start and read other threads

A workbench around every thread.

A worktree per thread

Each thread can work in its own git worktree on an agentloft/… branch. Merge back with a squash, or open a pull request and watch its checks.

Every turn checkpointed

Diffs for the last turn or the whole thread, and Undo changes on any turn. Checkpoints live in hidden git refs, out of your history.

A real terminal

Ghostty-powered, with tabs. Project actions put the commands your project runs often one click away, with their preview in the browser panel.

A browser the agent drives

Agents open pages, click and type through Agentloft's built-in MCP server. You watch the same tab, and can step in.

Files and documents

Code, Markdown and images, plus Word, Excel, PowerPoint and PDF previews. Leave a note on a slide, a cell or a passage and it goes to the agent.

Fork to any agent

Fork a thread to the same agent with its full context, or hand it to another agent with a summary you review first.

Agents keep running

A small daemon owns agents, terminals and git. Close or update the app and the work carries on; a thread out of usage resumes when its limit resets.

Automations

Run a prompt on a schedule: every few hours, weekdays at nine, or by cron. Each run is a new thread you can open.

Answers you can try

Agents can reply with a live page of their own making, right in the thread: a chart, a diagram, options to pick from.

  • NativeRust and GPUI, drawn on the GPU
  • YoursYour agents' own logins, no telemetry
  • Keyboard-firstCommand palette, windows and tab groups
  • OpenApache-2.0, built in the open

Your computer, from your phone.

Turn on web access and the same interface runs in any browser, served by Agentloft on your computer. Link it to your Google account here and open it from anywhere.

  • The same app, compiled to WebAssembly: terminals and the browser tab too
  • Cloudflare Tunnel connects the browser straight to your computer
  • This site only signs you in; your work never passes through it
  • Or open another computer's Agentloft over SSH
